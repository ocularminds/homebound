# FL-031 - Alexa-style web simulation while partner MCP is unavailable

**Area:** Alexa+ interface and voice

**Observed:** Alexa+ MCP and private partner tooling remain unavailable. Following discussion with Amazon, the project direction is to simulate the Alexa+ experience in a web frontend while retaining HomeBound's governed backend.

**Implemented:** A full-screen voice interface with a home-local clock, morning/afternoon/evening/night greetings, an animated Alexa-style ring, continuous listening between replies, and optional typed input. There is no sidebar or scene picker. Conversation and home details expose history, execution snapshots, pending Presence checks, and evidence. A Bedrock dialogue interpreter with no MCP access extracts conversation claims; the server gathers missing context before binding one exact action for the Bedrock/MCP execution loop. AgentSafe and Decionis still own authorization and dispatch. No authority result, approval, or signature is synthesized by the interface.

**Validation:** All 117 Python tests and 10 voice tests pass. The unchanged AgentSafe integration previously passed its 12 checks. Coverage includes greeting timezone boundaries, multi-turn context, cancellation, session isolation, exact tool binding, duplicate requests, uncertain execution, approval resume, secret-safe output, speech adapters, silence detection, microphone reuse, late permission results, and suspension during playback.

**Live browser confirmation (2026-10-07):** In the actual Codex in-app browser, generated speech passed through a real MediaStream, MediaRecorder, pause detector, Deepgram, Bedrock, MCP, AgentSafe, and Decionis. After the browser's initial audio gesture, three utterances ran without microphone or Send clicks: “open the side gate,” an expected delivery with an explicit 16:00 demo time, then simulated courier recognition. Alexa spoke each clarification and resumed listening automatically. The final result was `ALLOW/PERFORMED`, with a dossier verified against the official Decionis trust anchor. All greeting, transcription, chat, and speech requests returned 200, and only one microphone connection was acquired. Mute released every track and stopped the recorder. The desktop screen had no horizontal overflow. This test used generated speech, not the user's physical microphone.

**Model integration fixes:** Nova may return scalar labels wrapped in HTML-encoded quotes and may repeat a demo time from earlier dialogue. Quoted labels are normalized before strict validation. A repeated or ungrounded clock cannot change the server's current setting; an override needs an explicit time request in the latest utterance. The execution model receives concrete object schemas and exact arguments, including the policy's 30-second gate duration. Its planning text is removed before display or speech. A model response without a tool invocation cannot claim device execution.

**Existing browser session:** Reloading the user's actual page, with its existing microphone permission, started the greeting and listener automatically without another Start talking click. The 475-pixel-wide panel had no horizontal overflow. A live “Disable the alarm” request correctly asked whether an adult or child was at home and did not dispatch an action before clarification.

**Earlier failure:** A gate request in the original default scene returned `MANAGED_ESCALATION_MISSING` without a household or delivery identity. The conversational interface now asks for the missing details instead of requiring a scene selection. A missing approval handoff is still reported honestly if returned by the authority. The upstream Presence limitation in FL-029 remains unresolved.

**Boundary:** This is an independent Alexa-style simulation. Alexa+ is not connected. Browser microphone and autoplay rules may require an initial Start talking gesture. Speech is transcribed by utterance; there is no wake-word recognition or interruption while Alexa speaks. Quiet buffers stay in the browser. Conversation-derived identity, camera recognition, and explicit demo times are labelled simulation claims, not independent evidence. The greeting uses actual home-local time. Device states remain execution snapshots.
